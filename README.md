# Bank Management System

## Project Description
A simple Bank Management System developed using Python and Object-Oriented Programming.

## Features
- Create Customer Account
- Deposit Money
- Withdraw Money
- Check Account Balance
- View Transaction History
- Manage Multiple Accounts

## OOP Concepts
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

## Technologies Used
- Python
- Object-Oriented Programming
